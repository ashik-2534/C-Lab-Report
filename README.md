## How to compile and run

You need the GCC compiler (for example MinGW on Windows).

```bash
cd Lab-01_Basic-C-Programming/Q01_hello_world
gcc solution.c -o solution
./solution          # on Windows Command Prompt: solution.exe
```

Programs that read input will wait for you to type the values shown in `input.txt`.
